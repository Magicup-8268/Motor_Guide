# LAN 서버 연결 시간 초과 점검

- 날짜: 2026-07-15 (KST)
- 증상: 휴대폰에서 이전 주소 `192.168.0.11:5173` 접속 시 `ERR_CONNECTION_TIMED_OUT`.
- 원인: 5173 포트에 수신 대기 중인 Vite 개발 서버가 없었고, 현재 PC의 LAN 주소도 `192.168.1.24`로 변경됨. 기존 npm 기동 방식은 유지되지 않아 Vite를 Node 프로세스로 직접 기동함.
- 추가 원인: 현재 Wi-Fi `robotv_AP`가 Public 프로필이며, 해당 대역의 TCP 5173 인바운드 허용 방화벽 규칙이 없음.
- 조치: Vite를 `node node_modules/vite/bin/vite.js --host 0.0.0.0`로 직접 재기동. 방화벽 규칙 추가를 시도했으나 Windows 관리자 권한 거부로 적용 불가.
- 검증: `http://127.0.0.1:5173` 및 `http://192.168.1.24:5173` 모두 HTTP 200, `0.0.0.0:5173` 수신 대기 유지 확인.
- 상태: DONE_WITH_CONCERNS (휴대폰 접속은 관리자 방화벽 규칙 적용 후 최종 확인 필요)
